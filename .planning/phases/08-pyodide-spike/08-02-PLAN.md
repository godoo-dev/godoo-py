## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet → Odoo ingress | the ACA endpoint is publicly reachable for the TTL window |
| Logic App (UAMI) → Azure control plane | the UAMI can delete its own resource group |
| committed Bicep → public repo | the templates are world-readable in the LGPL repo |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-03 | Elevation / Tampering | UAMI RG-scoped Contributor | mitigate | Scope the roleAssignment to `resourceGroup()` ONLY, never subscription; `principalType: 'ServicePrincipal'`; UAMI lifetime == RG lifetime (torn down with the RG by the self-destruct). HIGH per ASVS V4 — the scoping IS the mitigation. |
| T-08-04 | Spoofing / Elevation | publicly-reachable Odoo admin login | mitigate | Throwaway DB + strong throwaway admin password passed as a deploy-time `@secure()` param (never committed, never reused); short TTL; self-destruct deletes the whole RG. |
| T-08-05 | Information Disclosure | over-permissive CORS | mitigate | `allowedOrigins` scoped to the exact page origin (parameter, never `'*'`); `allowCredentials: false`. (Enforced in Task 1.) |
| T-08-06 | Denial-of-control | self-destruct fails → endpoint/creds linger | mitigate | deploy.md documents the manual `az group delete -n rg-godoo-pyodide-spike` backstop (NOT GitHub Actions per D-05); the Logic App firing is verifiable (the RG disappears). |
| T-08-07 | Information Disclosure | secrets committed in Bicep | mitigate | Odoo/Postgres passwords are `@secure()` params supplied at deploy time; NO secret literal committed (secrets-handling rule). |
| T-08-SC | Tampering | npm/pip/cargo installs | accept | No package-manager install touches a project manifest in this plan (infra-as-code only). |
