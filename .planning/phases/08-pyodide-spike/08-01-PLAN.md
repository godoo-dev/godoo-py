    Create a standalone `PyfetchTransport` class that structurally satisfies the shipped
    `Transport` Protocol's five members with their exact signatures: a `session` `@property`
    returning `OdooSessionInfo | None`; async `authenticate(username, password)`; async
    `call(model, method, args, kwargs)`; SYNC `logout()`; async `aclose()`. Mirror
    `OdooSessionInfo(uid, session_id, db)` as a local `@dataclass` (do NOT import godoo — the
    package is `>=3.14`-gated and will not load under Pyodide's CPython 3.13, per D-07).

    Replicate the JsonRpcTransport happy-path wire shape but swap `httpx.AsyncClient.post` for
    `await pyodide.http.pyfetch(...)`: POST to `{base_url}/jsonrpc` with the JSON-RPC 2.0
    envelope `{"jsonrpc":"2.0","method":"call","id":1,"params":params}`. `authenticate` uses
    `params={"service":"common","method":"authenticate","args":[db, username, password, {}]}`
    and on a truthy uid builds `OdooSessionInfo(uid, session_id=str(uuid.uuid4()), db)` and
    stashes the password; `call` uses
    `params={"service":"object","method":"execute_kw","args":[db, uid, password, model, method, args, kwargs]}`.
    Parse the response with `await resp.json()` (the second `await` is mandatory —
    `FetchResponse.json()` is itself a coroutine, Pitfall 4); raise `RuntimeError(data["error"])`
    when `"error" in data`, else return `data["result"]`. `logout()` clears session+password
    synchronously; `aclose()` is a no-op (pyfetch holds no client to close).

    Construction MUST be synchronous (no `await` in `__init__`) — the real `transport_factory`
    is `Callable[[OdooClientConfig], Transport]` invoked once synchronously in
    `OdooClient.__init__`; all network work lives in the async methods. Full `_categorize_error`
    parity is NOT required (research §Strategy 3 — happy-path + raise-on-error suffices).
    Follow godoo style: `from __future__ import annotations` as the first line, dataclass not
    Pydantic, ruff line-length 120. This file is non-shipping evidence (D-09) — it lives under
    `spikes/`, is exempt from the `>=3.14` gate and mypy-strict, and need NOT be added to any
    `pyproject.toml`. NEVER `import godoo` here.
  </action>
