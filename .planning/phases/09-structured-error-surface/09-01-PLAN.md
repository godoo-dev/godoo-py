<objective>
Restructure OdooRpcError to expose structured fault fields and strip server tracebacks
from all user-visible output. This is the single breaking change sanctioned for v1.2:
OdooRpcError.data is renamed to .raw.

Purpose: Callers can handle RPC errors programmatically without parsing strings, and
server tracebacks/filesystem paths never reach logs or serialized output.

Output: Updated errors.py (private extractors, renamed attribute, __str__ override,
reshaped to_json) and updated test_errors.py (4 migrated assertions + new structured-
field test class covering ERR-01 through ERR-05).
</objective>
