<objective>
Deliver the code-generation vertical slice: type_mapper.py (pure ttype→string function) and codegen.py (CodeGenerator class), completing the library's ability to transform a live ModelSchema into a valid, programmatically-consumable Python TypedDict module.

Purpose: After this plan, a caller can do `CodeGenerator(introspector).generate(schema)` to receive a valid Python module string, or `CodeGenerator(introspector).write([schema], output_dir)` to write files to disk. The generated TypedDict classes are importable at runtime and support `get_type_hints(MyClass, include_extras=True)` for metadata extraction — the primary consumer interface.

Output:
- `type_mapper.py` — pure function `python_type_str(field: FieldSchema) -> str` implementing the full D-Mapping-1 wire-faithful mapping table
- `codegen.py` — `CodeGenerator` class with `generate(schema: ModelSchema) -> str` and `write(schemas, output_dir) -> None`, plus the private helper `_annotated_field_meta_str(field: FieldSchema) -> str` (codegen concern, lives here)
- Updated `__init__.py` adding `CodeGenerator` export
- `tests/test_type_mapper.py` — pure unit tests covering every ttype
- `tests/test_codegen.py` — output validation, compile check, get_type_hints round-trip, write() file output
</objective>
