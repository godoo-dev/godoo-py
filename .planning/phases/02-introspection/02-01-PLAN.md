<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Odoo RPC → FieldSchema builder | Raw dict[str, Any] from search_read is cast to typed FieldSchema; untrusted values from a remote Odoo instance cross here |
| names input → search_read domain | User-supplied model name strings are passed into a search_read domain; must be validated before RPC |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | `Introspector.get_schemas()` — empty names list | mitigate | Raise `OdooValidationError` before any RPC call (pre-condition guard, ASVS V5 input validation) |
| T-02-02 | Tampering | `Introspector.get_schemas()` — malformed model name (empty string, whitespace) | mitigate | Validate each name is a non-empty string; raise `OdooValidationError` on empty string entries |
| T-02-03 | Information Disclosure | `FieldSchema` stores raw help text from ir.model.fields | accept | Help text is Odoo's own field description; no user PII; consumer's responsibility to sanitise for display |
| T-02-04 | Elevation of Privilege | `IntrospectionCache` stale data — cached schema from one Odoo instance used with a different client | accept | Cache is per-Introspector-instance; callers who share an Introspector across Odoo instances are misusing the API (documented) |
| T-02-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed by this plan; all stdlib + existing workspace dependency |
</threat_model>
