| T-01-01 | Denial of Service | JsonRpcTransport — httpx.AsyncClient | mitigate | FIXES-03 adds configurable timeout; without it, slow Odoo responses block the event loop indefinitely. Default None is intentional (removes the hidden 5s httpx default); callers set timeout explicitly. |
| T-01-02 | Information Disclosure | OdooTimeoutError message | accept | Timeout error message includes `str(exc)` from httpx, which may contain the target URL. URL is already known to the caller since they configured it. Low risk. |
| T-01-03 | Tampering | Exception handler ordering | mitigate | TimeoutException handler placed before RequestError handler (enforced by FIXES-02). Regression test guards catch order reverting. |
</threat_model>
