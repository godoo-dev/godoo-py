## What Was Built

### type_mapper.py — pydantic_field_str()

New function signature: `pydantic_field_str(field, in_set, classname_fn) -> tuple[str, str]`

Returns `(annotation_str, default_expr_str)` for assembly as `{name}: {annotation} = {default}`.

Full mapping table:
- `char/text/html/image/binary/serialized/reference` → `("Optional[str]", "None")`
- `integer` → `("Optional[int]", "None")`
- `float/monetary` → `("Optional[float]", "None")`
- `boolean` → `("bool", "False")` — non-Optional per CF-04
- `date` → `("Optional[date]", "None")`
- `datetime` → `("Optional[datetime]", "None")`
- `many2one` in in_set → `("Optional[Ref[TargetClass]]", "None")` with cross-import
- `many2one` not in in_set → `("Optional[Ref[int]]", "None  # target.model")`
- `one2many/many2many` → `("list[int]", "[]")`
- `selection` static → `("Optional[Literal['a','b',...]]", "None")`
- `selection` dynamic → `("Optional[str]", "None")`
- `json/properties` → `("Optional[dict[str, Any]]", "None")`
- unknown ttype → `("Optional[Any]", "None")` + WARNING log

### codegen.py — CodeGenerator (Pydantic emitter)

New constructor: `CodeGenerator(introspector, in_set=frozenset())`

`generate(schema)` emits a complete Python file:
- Header comments (`# AUTOGENERATED by godoo-introspection`)
- `from __future__ import annotations`
- Dynamic stdlib imports (date/datetime only when needed)
- Dynamic typing imports (ClassVar, Optional always; Literal/Any conditionally)
- `from godoo.client._pydantic_transform import OdooBaseModel`
- `from godoo.client.typed import Ref` (only when any many2one fields)
- Per in-set many2one target: `from .{stem} import {TargetClass}`
- `class {ClassName}(OdooBaseModel):`
- `__odoo_model__: ClassVar[str] = "model.name"`
- `id: int` (always, no Optional, no default)
- Per non-id field: Pydantic annotation via `pydantic_field_str`
- `pass` when no non-id fields

Threat mitigation T-07-01 preserved: `field_name.isidentifier()` guard in generate() field loop.
Threat mitigation T-07-02 preserved: `repr(v)` for selection values in pydantic_field_str.
Threat mitigation T-07-03 preserved: model name embedded as double-quoted string literal.
