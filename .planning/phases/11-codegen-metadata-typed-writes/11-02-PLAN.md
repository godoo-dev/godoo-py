## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller (typed OdooBaseModel instance) → _serialize_for_write | Caller controls which fields are in model_fields_set via explicit assignment; the serializer must not allow readonly fields through regardless |
| _serialize_for_write → wire payload | Payload goes directly into the JSON-RPC call; malformed or oversized values reach Odoo unchanged |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-02-01 | Tampering | Readonly field bypass via explicit set | mitigate | _serialize_for_write unconditionally skips odoo_readonly=True fields regardless of model_fields_set — no bypass path exists (WRITE-04) |
| T-11-02-02 | Tampering | x2many silent REPLACE via list[int] set | mitigate | _serialize_for_write raises OdooValidationError before any RPC when odoo_x2many=True field is in model_fields_set (WRITE-05, D-01) |
| T-11-02-03 | Tampering | Unset-field leakage (None overwriting DB values) | mitigate | Serializer iterates model_fields_set exclusively — model_dump() is never called; unset fields are never in the payload |
| T-11-02-04 | Tampering | Write with id=None issuing write([[None], {...}]) | mitigate | write(instance) guard raises OdooValidationError before RPC when instance.id is None |
| T-11-02-05 | Information Disclosure | Unexpected type reaching Odoo transport | accept | Unknown types fall through to payload[field_name] = value — Odoo's own JSON-RPC layer will reject non-serializable values; severity low (no PII exposure; runtime error at Odoo level only) |
| T-11-02-06 | Spoofing | Pydantic module not installed | mitigate | ModuleNotFoundError caught in dispatch branch → OdooValidationError with install hint; no silent failure |
| T-11-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this plan |
