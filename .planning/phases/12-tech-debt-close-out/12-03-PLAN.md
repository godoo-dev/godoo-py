the direct-container path and the TestHarness path compute the same key for the same inputs.

this is a BREAKING CHANGE to the OdooTestContainer public API (acceptable at 0.2.x pre-1.0,
per D-08 from CONTEXT.md). All in-repo callers are updated in this plan.

Output: Updated container.py (required properties param), updated test_container.py (13 callers),
updated conftest.py (1 caller), new test_snapshot_key_parity.py (2 unit tests), updated
docs/testing.md and packages/godoo-testcontainers/README.md.
