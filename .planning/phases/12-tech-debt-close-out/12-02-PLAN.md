Root cause (RESEARCH.md DEBT-03 section):
  asyncio.run(_generate_async(...)) evaluates left-to-right:
  1. _generate_async(...) creates a coroutine object
  2. asyncio.run is called with the coroutine, but the monkeypatched _raise raises immediately
  3. The coroutine object is never awaited → CPython RuntimeWarning on GC
