    async save_snapshot(pg: Any, cfg: SnapshotConfig, database: str, pg_user: str) -> None:

    - Atomic rename: os.replace(tmp_host, cfg.host_path)
    - Log success at logger.info

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host filesystem → container (bind-mount) | addons_path from caller is bind-mounted into the Odoo container |
| Host filesystem → container (bind-mount) | cache_dir is bind-mounted into the Postgres container with rw access |
| container exec output | pg_dump/restore output (bytes) decoded and logged |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-02-01 | Tampering | addons_path bind-mount path traversal | mitigate | _build_addons_cmd calls p.resolve() on every addons path before passing to with_volume_mapping; resolved paths prevent relative traversal (e.g. ../../../etc) |
