## Cross-Phase Integration

Verified by `gsd-integration-checker`. **All wiring sound — 0 broken flows, 0 orphaned exports, 0 missing connections.** Full 440-test unit suite passes; integration tests (`@pytest.mark.integration`) require Docker.

### Flow 1 — Codegen → Typed Read → Relation Resolve → Typed Write  (WIRED)
`type_mapper.pydantic_field_str()` 4-tuple → `codegen` emits `Field(json_schema_extra=...)` → generated class subclasses `OdooBaseModel` (`_pydantic_transform`) → m2o wire transform stamps `Ref._target_cls` via `_ref_target_class()` → `client.read(type[T])` typed dispatch / `client.read(ref)` batched resolve → `client.write(instance)` → `_serialize_for_write` (skip id, skip readonly, raise on x2many, Ref→int, None→False, dt→ISO). Exercised by TEST-01 (`test_codegen_read_write_roundtrip`, integration) and TEST-02 (`test_typed_dispatch.py`).

### Flow 2 — Error Surface Integration  (WIRED)
`.data`→`.raw` rename complete: no `.data` attribute access remains in `packages/` source (only `ir.model.data` strings + the rename comment). Phase 10's untyped-Ref guard and Phase 11's x2many guard both raise `OdooValidationError` from Phase 9's restructured `godoo.client.errors`. New `OdooMissingError` raise point (missing record for a Ref id) uses the restructured hierarchy. `to_json()` no longer emits `details`/`raw` keys; no regression path found.

### Flow 3 — Tech Debt (DEBT-01..04)  (WIRED, self-contained)
CI YAML bumps (no Python dependency), `cli.py` `_coro.close()` in `finally` + `test_cli.py` patches `_generate_async`, `OdooTestContainer.properties` required keyword with all 13+ callers updated (`conftest.py`, `harness.py`, `test_container.py`). `TestHarness` defaults `properties` to `{}`, satisfying the required arg.

### Integration note (non-blocking)
**REL-04 doc divergence:** the 10-02 SUMMARY describes the untyped-ref guard as `_target_cls is None`, but the live `client.py` guard is `not hasattr(_target_cls, "__odoo_model__")` — stricter (also blocks `Ref[object]`). The live behavior is strictly more correct and is covered by `test_read_object_target_ref_raises_before_rpc`. Documentation underspecification, not a code defect.
